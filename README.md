# Full Stack Java Programming experiments

Experiments follow the supplied lab list in order. Experiment 11 (Spring Boot) is intentionally omitted. Experiments with multiple programs or files are grouped in folders.

| Experiment | Topic | Location |
|---|---|---|
| 1 | Classes and objects | `01-classes-objects` |
| 2 | Method and constructor overloading | `02-overloading` |
| 3 | Inheritance and exception handling | `03-inheritance-exceptions` |
| 4 | Generic and HTTP servlets | `04-servlets` (Jakarta Servlet) |
| 5 | JSP login validated using JDBC and a servlet | `05-jdbc-login` |
| 6 | Implicit and explicit JSP objects | `06-jsp-objects` |
| 7 | HTML, CSS, and JavaScript website | `07-html-css-js` |
| 8 | JavaScript email validation | `08-email-validation` |
| 9 | DOM background color rotation | `09-dom-background` |
| 10 | React Hooks color selector | `10-react-hooks` |

Java console programs can be compiled with `javac FileName.java` and run with `java ClassName`. Servlet/JSP examples need a Jakarta-compatible servlet container; experiment 4 source follows the supplied `javax.servlet` API and may require a matching older container. Experiment 5 uses Jakarta Servlet and MySQL Connector/J; configure the database using the notes in its folder. Experiment 10 is a Vite React project (`npm install`, `npm run dev`).
